# Sentinel X
### Cyber Incident Response & SOC Simulation Platform

**Sentinel X** is an interactive Security Operations Center (SOC) simulation platform designed to demonstrate cybersecurity monitoring, alert investigation, incident response, and security operations workflows through a unified web-based dashboard.

The project simulates realistic security scenarios and provides an interactive environment for managing security alerts, investigating threats, and tracking incident response activities.

## Key Features

- **Security Dashboard:** Centralized overview of security alerts, threats, and system status.
- **Alert Management:** Investigate, block, and ignore security alerts.
- **Incident Response:** Contain, resolve, and close security incidents.
- **Investigation Workspace:** Analyze security events, isolate affected devices, and create incidents.
- **Threat Hunting:** Explore security records and monitor threat response statuses.
- **Employee & Device Monitoring:** View employee security activity and device isolation status.
- **Security Reports:** Generate reports reflecting security events and response actions.
- **Role-Based Access Control (RBAC):** Manage permissions for different user roles.
- **Persistent State Management:** Preserve simulated security actions across page refreshes.

## Technologies Used

- HTML5
- CSS3
- JavaScript
- JSON
- Browser Local Storage

## Project Scope

Sentinel X is an educational and portfolio-oriented SOC simulation. It demonstrates cybersecurity concepts and incident response workflows using simulated security data.

It is not a production SOC platform and does not perform real-world endpoint isolation or network attack prevention.
